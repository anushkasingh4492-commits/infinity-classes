# Infinity Classes — Complete Rebuild

A from-scratch Next.js + TypeScript marketing site for Infinity Classes.

## Stack
- Next.js / React / TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Responsive CSS with CSS 3D / motion effects
- No external image dependency beyond Google Fonts
